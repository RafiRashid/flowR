# A propos
L'objectif de l'application est de visualiser :

- les flux de patients en milieu hospitalier entre les différents services,
- les flux de patients entre les différents hopitaux du GHU Nord,
- fournir les tables de référentiels du PMSI (services, UMA, CIM, CCAM, GHM, GHS, tarifs)

# Données
Données générées à partir des données PMSI (séjours et passages hospitaliers) en flux origine / destination.
